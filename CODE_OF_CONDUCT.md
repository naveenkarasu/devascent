# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The full text is published at:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be respectful and constructive. We want participation in DevAscent to be
a welcoming, harassment-free experience for everyone, regardless of background or
identity.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when
someone is representing the project in public spaces.

## Reporting

If you experience or witness unacceptable behavior, report it to the project
maintainer via their GitHub profile (<https://github.com/naveenkarasu>) or, for
sensitive matters, through GitHub's private contact options on the repository.
Reports will be reviewed and handled as confidentially as is practical. As a solo
project, responses are best-effort.
